## Contexto / Persona
Lucas, 22 anos, gamer casual que tem vários jogos espalhados em Steam, PS5 e Xbox. Ele nunca sabe o que jogar, esquece quais jogos já zerou e não consegue recomendar nada para os amigos. Ele quer um sistema para catalogar, avaliar e organizar sua coleção.
